GlanceWAM 提出面向世界动作模型的稀疏测试时想象方法

GlanceWAM 研究提出异步生成未来视觉想象、直接在潜在空间解码动作的方法，作者报告其兼顾机器人控制速度与任务成功率。根据当前材料，该方法共享单个视频 DiT 骨干，由异步提议模块在后台想象数秒后的单帧，动作头以 48 ms 的控制节奏解码动作块，并通过非干扰注意力掩码和适应前瞻信息陈旧性的训练支持异步运行。

基于摘要arXiv:2608.23927v2研究解读、日期与资料入口
研究变化
作者提出 GlanceWAM，针对现有世界—动作模型（WAM）的速度与成功率权衡：在控制频率下同步生成视频会带来过高延迟，而放弃测试时视觉想象又会损失任务成功率。该方法在单个共享的视频 DiT 骨干上解耦想象与控制：异步提议器以较慢节奏在后台生成数秒后的单个前瞻帧，动作头直接在潜在空间中按控制节奏解码动作块，无需等待视频生成，作者报告每块控制延迟为 48 ms。方法使用隔离视频表征的非干扰注意力掩码，以及适应异步前瞻信息老化的时域训练，使视觉想象移出控制关键路径。

Budgeted Cache Repair 提出跨上下文 KV 缓存复用的预算内修复方法

Budgeted Cache Repair（BCR）研究提出按固定预算重算缓存行，作者报告其将 GSM8K 准确率恢复至完整预填充水平，同时仍让多数调用使用缓存。

基于摘要arXiv:2610.02233v1研究解读、日期与资料入口
研究变化
作者提出 Budgeted Cache Repair（BCR，预算约束的缓存修复），针对跨上下文 KV-cache 复用在新前缀下预测共享片段的键和值、而不重新计算时产生的准确率损失。作者报告，仅决定是否复用整个缓存不能消除这一代价，有效做法是选择缓存中哪些部分需要重算，且选择粒度越大，精细选择的收益越低。BCR 从组装后的缓存草拟两个 token，按这两个 token 对缓存各行的注意力给行排序，再以三种布局之一精确重算固定预算内的行；一行对应一个 token 的键和值。其变化是将草拟结果用于选择修复对象，而非用作是否复用缓存的门控，并实际支付部分重算成本。
