使用规则

AlgorithmHot · 科研热点整理公开研究来源的标题、中文摘要和原文入口。摘要、分类与评分由模型生成，可能有误，阅读时以原始材料为准。网页、RSS、公开 API 与 MCP 均可匿名使用。

1. 内容依据

本站持续采集公开研究来源（arXiv 每日公告、期刊新论文、研究机构博客与社区论文精选），由模型写出中文标题、摘要、推荐理由并给出分类与评分。摘要只依据当前取得的材料，多数情况下是论文摘要；没有读到全文时不代表全文内容。

论文摘要、作者报告的实验、代码与权重入口、独立复现是不同层次的证据。没有报告的信息保留未知；入选本站或获得社区关注，均不表示研究结论已经过验证。重要事实请回到原文核对，核对前不要把本站摘要当作研究结论引用。

条目日期按来源上线日记录：arXiv 用公告日，期刊用首次在线日期，其余来源用本站发现时间。日报收北京时间前一天 08:00 至当天 08:00，等当天早上的 arXiv 公告处理完后出刊，最迟 12:00。

2. 原始内容与版权

原文及其附带的代码、数据和权重，权利与许可由各来源决定。本站默认只展示摘要和原文链接，不授予第三方内容的转载、商业使用或再分发许可。

3. 来源方的更正与下架

如果你是来源方或作者，希望更正、下架或调整展示方式，请通过反馈页联系我们，我们会尽快处理。

4. 使用本站的数据

个人阅读、研究和组织内部使用可以直接使用。商业产品、公开转载或批量再分发本站生成的摘要与评分，请先通过反馈页联系取得同意。

5. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口，读者访问不会触发模型调用。请按响应中的缓存时间轮询，遇到 429 请遵守 Retry-After，不要并发重试。

6. 免责

本站按“现状”提供，不保证内容完整、准确和持续可用。
