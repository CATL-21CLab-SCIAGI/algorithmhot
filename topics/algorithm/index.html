    Soft-MTP 通过 KL 梯度恢复改进多 token 预测训练

    Soft-MTP 研究提出移除多 token 预测训练中的噪声梯度残差，仅保留 KL 自蒸馏信号，以改善模型学习与推测解码。根据当前材料，作者将 MTP 交叉熵梯度精确分解为 KL 自蒸馏项与低信噪比残差，并在两个分布共享线性输出头的条件下，通过直通梯度路由组合交叉熵梯度，精确恢复 KL 梯度，无需词表大小的 logit 矩阵且兼容标准融合交叉熵内核。
