KaliBench 研究提出面向 Kali Linux 安全工具调用的细粒度基准与免运行可验证奖励

KaliBench 研究提出面向 Kali Linux 的自然语言到命令行翻译基准，用于评估 LLM 的工具选择与参数构造能力。根据当前材料，数据集包含 8,504 个查询—命令对，覆盖 1,642 个工具、23 个能力维度和 5 个安全阶段，采用确定性规范化与别名感知评估，并结合 LLM 验证、沙箱终端执行和人工参与改进进行多阶段验证。

RPG 研究提出通过仿真练习自主改进机器人执行系统的方法

RPG 研究提出无需更新模型权重的机器人执行系统自主改进框架，通过仿真练习修订可复用符号技能与系统提示词。根据当前材料，该框架从离线数据集识别操作能力并构建练习任务，结合执行反馈、仿真器特权状态及可用数据集视频诊断失败，经跨任务评估后保留候选修改及合并版本，测试时由多模态 LLM 协调感知与机器人控制。

ScholarCatalyst 提出检索研究启发文献的基准

ScholarCatalyst 研究提出检索能启发新研究的文献的基准，作者报告智能体搜索未优于嵌入检索。根据当前材料，研究通过自动化流程支持作者标注，由 207 篇近期计算机科学论文的 184 位主要作者判断候选文献是否曾经或可能推进其项目，并提供详细理由。

SourceLearn 提出来源学习方法，让智能体持续积累特定来源的理解能力

SourceLearn 研究提出通过持久化来源模型，让 LLM 智能体在重复使用权威来源时持续积累可复用的理解能力。根据当前材料，该方法结合自主识别理解缺口并重访来源的学习机制，以及利用下游任务经验发现局部表征缺口与反复出现的知识组织需求的学习机制，两者的持久化更新均依据权威来源重新构建。
