    结果奖励强化学习带来什么：完成率、可靠性，以及有限的解题范围拓展

    该研究报告，结果奖励强化学习在物理与数学任务上的 pass@1 收益主要来自完成率和可靠性提升，较少拓展解题范围。根据当前材料，作者在固定 token 预算下比较了 20 个已发布的 RL 模型（1.5B 至 32B）及其初始思考模型，并将收益拆为预算内完成作答、完成后的正确率，以及双方各采样八次均答错所界定的净新增解题范围。

    推荐理由：将解题收益拆成完成率、可靠性与能力覆盖范围，有助于区分固定预算下的行为改善与新增解题能力，避免只凭单次成功率判断训练收益。
