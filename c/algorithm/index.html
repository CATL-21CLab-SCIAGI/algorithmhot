    Horizon-Scalable Q-Learning 提出面向长时域的自适应 Q 学习方法

    Horizon-Scalable Q-Learning（HQL）提出自动平衡单步与多步回报的方法，以改善长时域离线 Q 函数学习。根据当前材料，仅当评论家对数据集动作的估值不低于从 BC 策略采样的 N 个动作中的最高估值时，HQL 才沿该动作延长目标，否则退回单步目标。

    推荐理由：按动作价值自适应选择回报步数，为长时域离线价值学习提供可迁移思路，并减少对动作密度的依赖以适配更灵活的策略。

    Flide 通过精确状态分叉加速决策模型推理

    Flide 研究提出面向决策模型的推理引擎，作者报告其查询速度最高可达 vLLM 和 SGLang 的 9.5 倍。根据当前材料，该方法将请求的逻辑树与单一扁平 token 流中的物理执行解耦，通过 ForkAttention 和 GPU 驻留索引处理标准注意力及循环 Gated DeltaNet 层，并在精确算术条件下保证各查询分支与单独前向计算一致。

    推荐理由：将决策分支映射为扁平执行流并复用历史检查点，为需要共享前缀且保持分支计算一致性的智能体推理提供实现思路。
