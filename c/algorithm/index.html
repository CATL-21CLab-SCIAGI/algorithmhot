    Any Time, Any Space：以世界状态为中心的智能体视频生成框架

    Any Time, Any Space（ATAS）提出以世界状态为中心的智能体视频生成框架，旨在保持长视频跨镜头的时空一致性。基于摘要，该框架将剧本编译为带有位置、相机和事件时间引用的镜头请求，生成前检索已配准静态几何的场景记忆与按场景、事件和时间索引的动态事件记忆，生成后重建并配准片段，仅在审查与状态检查通过后更新记忆。
