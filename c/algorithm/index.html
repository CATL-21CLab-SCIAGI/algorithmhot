    每个 token 都需要自己的教师：MTA-OPSD 提出多教师自适应策略内自蒸馏

    MTA-OPSD 研究提出逐 token 自适应选择教师的策略内自蒸馏方法，作者报告其在 Qwen3 数学推理任务上优于现有 OPSD 方法。根据当前材料，教师干预预实验显示，同一回答中不同 token 的教师偏好存在差异，可通过多数投票和基于 KL 的选择识别偏好教师；该方法据此构建多教师候选池，在训练中为每个 token 选择教师。

    推荐理由：逐 token 选择教师的设计为自蒸馏后训练提供了可迁移思路，当前性能证据限于 Qwen3 的数学推理任务。

    研究报告 Muon 使第一层 MoE 的专家负载更难均衡

    研究报告，在具有 55M 和 108M 活跃参数的 MoE 模型中，Muon 使第一层专家负载更难均衡，主要影响来自网络其余部分而非路由器的优化器选择。根据当前材料，作者以层内路由偏置最大值与最小值之差衡量均衡难度；在通过较短训练调优的学习率下，Muon 在每个随机种子上都增大了第一层的偏置跨度，平均约翻倍，其他层变化较小。

    推荐理由：通过区分路由器与网络其余部分的优化器作用，研究为小规模 MoE 训练中的负载失衡诊断和学习率选择提供了实验依据。
