    WaveGen 通过内部频谱轨迹学习实现端到端文本到波形生成

    WaveGen 研究提出基于扩散模型的端到端文本到波形生成框架，在单一模型内联合学习内部频谱轨迹与目标波形轨迹。根据当前材料，该方法采用 Spectral Forcing、解耦扩散头和多尺度频谱 v-loss，并在模型内部完成文本与语音对齐，不依赖单独训练或外部解码的中间表示、外部时长预测器、自监督表示及语义蒸馏。

    推荐理由：内部频谱轨迹与波形轨迹的联合学习，为减少语音合成对外部表示和对齐模块的依赖提供了可参考的架构与训练方案。

    APEX 通过条件偏移实现少步流式视频生成

    研究将 APEX 扩展到流式视频生成，通过条件偏移在生成器内部估计生成分布的速度场，移除 DMD 所需的独立 fake-score 网络。原始文本条件用于生成，偏移条件用于共享参数的分布估计，同时保留 S2-Avatar 的冻结参考教师、Self-Replay Forcing 和感知正则化。

    推荐理由：条件偏移让生成与分布估计共享参数，为流式视频蒸馏减少独立网络开销提供思路，材料给出了匹配训练条件下的资源比较。

    MAEP 提出面向 MoE 多模态大语言模型的模态感知专家剪枝方法

    MAEP 研究提出无需训练的模态感知专家剪枝框架，作者报告可减少约 27 GB 的 BF16 专家权重占用。根据当前材料，该方法在单次前向传播中拆分模态重要性，以衡量移除专家后 MoE 输出变化的 Delta-H Output（ΔH）和低注意力视觉 token 为依据，将文本侧重要性用于保留、视觉侧重要性用于剪枝，并跨层全局排序专家。

    推荐理由：按模态拆分专家重要性为多模态模型压缩提供了可迁移思路，作者报告的优势主要体现在多模态基准而非纯文本任务。

    RidgeFill：无需训练的后层缓存填充加速预填充

    RidgeFill 研究提出无需训练模型的后层缓存填充方法，通过跳过提示的大部分上层计算来缩短预填充时间。根据当前材料，该方法用校准文本的一次遍历闭式拟合岭回归映射，从分割层状态预测后续各层输入，再用各层原有投影写入缓存；选定行、末尾数千个 token 和所有解码步骤仍运行完整模型，不丢弃 token。

    推荐理由：填充区域检索、远距离依赖损失与键值替换测试，可用于定位缓存近似的误差来源，避免全局平均损失掩盖局部退化。

    onóna：采用权重绑定输出映射的双嵌入表方法

    onóna 提出双嵌入表参数化方法，在保留输入输出权重共享的同时增强语言模型的输出表达力。Transformer 输入取两个嵌入表的平均值，输出端混合这两个表各自定义的 softmax 分布；混合权重仅由当前输入 token 决定，可在模型推理前预计算，Transformer 主体保持不变。

    推荐理由：双嵌入表与输出分布混合提供了扩展语言模型输出表达力的具体方案，可用于权衡权重共享收益与额外参数、投影开销。
