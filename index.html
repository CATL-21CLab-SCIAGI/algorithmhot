    Intrinsic Distribution Matching 提出以显式矩约束改进文生图蒸馏

    Intrinsic Distribution Matching（IDM）研究提出在分布匹配蒸馏中加入显式矩约束，以改善单步和少步文生图的提示细节还原。根据当前材料，该方法将反向 KL 场分解为高斯矩分量与非高斯残差，保留完整 DMD 修正，并使用生成器的指数移动平均（EMA）副本匹配特征均值和逐坐标标准差，无需外部特征编码器。

    推荐理由：通过在分布匹配蒸馏中加入显式矩约束，提供改善少步文生图提示细节还原的方法，并以受控消融检验新增损失的贡献。

    多模态大语言模型检索头研究：跨模态共享机制与定向优化

    该研究报告，多模态大语言模型的检索头在音视频输入中仍保持稀疏且跨模态共享，并可作为提升文档检索的优化目标。根据当前材料，作者构造答案分别通过语音或屏幕呈现的配对输入，在固定证据内容的条件下比较18个语言、视觉语言及全模态模型检查点，发现全模态模型大体保留骨干模型的检索头。

    推荐理由：通过固定证据内容比较跨模态检索头，并以排序目标优化其注意力，为多模态文档检索提供可迁移的优化思路。

    CoSTA 提出兼容原有组件的后置适配框架，通过解耦生成与合成的 token 空间，提高语音对话模型的推理效率。根据当前材料，该方法保留原有语音分词器与解码器，通过均值初始化的词表扩展、发音适配和对话适配引入压缩表示，并在合成前确定性地展开回原始语音 token 空间。

    LOWN 提出基于一致性认证的视觉路由，让扩散视觉语言模型按需处理图像

    LOWN 研究提出按需处理图像的解码方法，作者报告其在十个基准上保留 LLaDA-V 99.6% 的得分，平均仅使用 35.3% 的解码 FLOPs。该方法先在不输入图像时预测被掩码的 token，仅在预测与上一次图像条件预测不一致时处理图像，并根据通过一致性认证的 token 数量决定当前步骤解除多少掩码，无需训练或调节阈值。

    推荐理由：通过预测一致性自适应决定何时读取图像，为减少扩散视觉语言模型的重复计算提供方法，并保留与视觉 token 剪枝组合的空间。

    学习率调度可能缺乏原则：权重归一化训练中的有效学习率调度

    该研究提出有效学习率（ELR）应成为调度目标，并报告权重归一化（WN）训练的收益主要来自 ELR 轨迹，而非归一化本身。根据当前材料，匹配 ELR 轨迹后，WN 与权重衰减（WD）的训练损失动态大体趋于一致；据此提出的 AIR（Affine Inverse-square-Root decay）结合理论推导的 1/t 衰减与仿射调整，在有限训练周期内满足指定的峰值和终点学习率。

    推荐理由：通过匹配有效学习率轨迹区分归一化与调度带来的收益，为比较权重归一化和权重衰减训练及设计调度提供可迁移方法。
