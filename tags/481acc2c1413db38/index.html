    FLUX.1 Kontext 研究提出用于可控灯光开关的 LoRA 方向提取方法

    该研究提出面向 FLUX.1 Kontext 的 LoRA 方向训练方法，旨在控制室内图像中人工光源的开关并保留原始场景特征。根据当前材料，作者将任务分解为两个独立表述，从扩散模型的流场中提取 LoRA 适配器作用的纯方向，并设计专用损失函数以保障逆向变换的真实感。所得增量图还用于更精细地调节光照颜色与色温；作者称该微调方法无需大型训练数据集，但材料未提供数据规模、比较设置或量化结果。

    RASS 提出面向扩散草稿树的排序感知推测采样方法

    RASS 研究提出排序感知的草稿树验证规则，作者报告其在所评估的扩散生成设置中均优于 D-GRS。根据当前材料，该方法沿提议分布与目标分布的均值位移方向排列候选，优化排序位置的抽样权重以减小所选提议分布与目标分布的总变差，再通过最大耦合与残差校正确保任意排序权重下的精确采样，排序无需额外目标模型评估。
