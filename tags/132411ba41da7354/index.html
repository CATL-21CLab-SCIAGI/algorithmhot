    从需求到攻击树：LLM 多智能体框架用于设计阶段安全审查

    该研究提出从产品需求文档和架构图开展设计阶段安全分析的 LLM 多智能体框架，作者报告其审查质量优于单次生成与消融基线。根据当前材料，框架将架构图解析为图表示，以误用案例连接系统组件与攻击路径，生成攻击树，并通过验证与改进循环过滤缺乏依据的发现，提供缓解措施及供专家审查的候选架构修订建议；推理时不检索 Common Weakness Enumeration（CWE）数据库。
