SourceLearn 提出来源学习方法，让智能体持续积累特定来源的理解能力

From Knowledge Access to Source Learning: Developing Source-Specific Competence

arXiv · AI 与机器学习发表 2026-10-02 01:50 北京时间查看原文 ↗
基于摘要作者报告 · 独立复现未核验

SourceLearn 研究提出通过持久化来源模型，让 LLM 智能体在重复使用权威来源时持续积累可复用的理解能力。根据当前材料，该方法结合自主识别理解缺口并重访来源的学习机制，以及利用下游任务经验发现局部表征缺口与反复出现的知识组织需求的学习机制，两者的持久化更新均依据权威来源重新构建。

研究变化

作者提出 source learning（来源学习）：针对持续使用同一权威来源时，现有方法主要将其视为重复访问、未充分利用重复使用来逐步加深理解的问题，以持久化的来源模型积累可复用、针对特定来源的能力，涵盖对来源知识的结构、解释与应用的理解。作者提出的 SourceLearn 结合两种机制：Self-Directed Source Learning 识别尚未充分理解的内容并自适应重访来源；Task-Guided Source Learning 利用下游任务经验发现局部表示缺口，以及知识组织中的反复需求。两种机制均由学习信号决定需要重新考察的内容，而持久化更新依据权威来源重新构建。

适用任务

资料支持的研究范围是：LLM 智能体依赖持久存在的外部权威来源，连续解决知识密集型任务，并在重复使用同一来源的过程中积累可复用理解。作者报告在五个基准、三个 LLM 后端上评估；具体任务类型、基准名称、来源领域与格式、LLM 名称及规模未知：当前资料未提供。

作者报告的比较条件

作者报告，在五个基准与三个 LLM 后端构成的 15 种设置中，SourceLearn 在其中 13 种设置取得最佳表现；相对 Hybrid RAG 的增益最高达 22.6 点，该数字是最高增益，不能视为所有设置的普遍或平均增益。摘要未说明这些点对应的具体指标、量表或是否为百分比点。作者还报告，相对静态来源表示及基于经验的记忆基线，总体上有显著改善，但未提供对应数值，也未提供统计显著性检验信息。除 Hybrid RAG 外的具体基线名称、比较系统总数、数据集与样本数量、各设置的单独结果、平均增益、硬件、计算预算、训练与推理配置及其他计算设置均未知：当前资料未提供。

证据限制

证据仅限所提供的摘要，未核对全文；上述性能结果均为作者报告，当前资料不包含独立复现证据。13/15 的最佳表现与最高 22.6 点增益仅能按作者报告的评估范围理解，不能据此推断所有任务、来源或模型上的效果，也不能仅凭最佳表现声称推断研究质量。摘要未明确陈述方法限制；具体评估协议、指标定义、数据划分、重复运行与误差范围、消融实验、学习及存储成本、长期使用效果、失败情形和范围外泛化验证均未知：当前资料未提供。代码、数据及可运行实现的开放情况亦未知，不能据此断言研究本身没有这些材料或验证。
