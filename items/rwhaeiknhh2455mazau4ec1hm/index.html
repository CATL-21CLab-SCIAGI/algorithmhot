CONTRA 提出通过程序行为差异筛选 LLM 代码生成中的澄清问题

CONTRA: Discovering and Qualifying Behavior-Changing Questions for Selective Clarification in LLM Code Generation

AI 导读

CONTRA 研究提出一种无需训练的选择性澄清方法，通过语义筛选与执行检查识别会改变生成代码行为的问题。根据当前材料，该方法先排除与所需行为无关或需求已解答的问题，再针对两种合理回答生成程序，在共享输入上检查稳定的行为差异，并依据交互历史选择提问或停止。

基于摘要arXiv:2610.01769v1
研究变化
作者提出 CONTRA，一种无需训练的方法，用于在代码需求描述不充分时识别关键澄清问题，同时减少不必要的提问。其目标是降低编码代理自行假设用户意图所造成的行为偏差，以及后续开发依赖这些假设后增加的纠正成本。CONTRA 将广泛的问题发现与语义及执行层面的筛选结合：先生成候选问题，剔除与所需行为无关或已被需求说明解决的问题；针对每个剩余问题，分别依据两个合理答案生成程序，在共享输入上检查是否存在稳定的行为差异；最后利用交互历史选择已通过筛选的问题，或停止提问。
适用任务
资料支持的应用场景是编码代理在需求不充分时进行选择性澄清，以确认用户期望的程序行为。作者在 ClarifyCodeBench 上使用四个编码代理开展实验，并报告将 CONTRA 实现为 Claude Code 插件，以便在日常开发中集成选择性澄清。具体编程语言、代码库类型、需求规模及其他领域的适用范围未知：当前资料未提供。
作者报告的比较条件
作者报告，在 ClarifyCodeBench 上，CONTRA 在全部四个编码代理中均取得最高 F1，其宏平均 F1 比最佳基线高 13.88 个百分点；该数字是宏平均 F1 的绝对百分点差，不能解释为每个代理均提升 13.88 个百分点。摘要未给出四个代理的名称、最佳基线身份、基线总数、各方法的 F1 绝对值或宏平均的具体分组口径。另在使用相同 LLM 和评估协议的条件下，作者报告 CONTRA 的澄清召回率和 F1 均高于 Claude Code 与 OpenHands 这两个编码执行框架，但未给出差值或绝对值。数据集为 ClarifyCodeBench；样本量、任务数量、LLM 名称与规模、硬件、计算预算、推理参数、运行次数、耗时和成本均未知：当前资料未提供。方法被作者描述为无需训练。
证据限制
当前证据仅为摘要，未核对全文；方法流程、比较结果及 Claude Code 插件实现均为作者报告，当前资料没有提供独立复现证据。摘要所报告的实验范围为 ClarifyCodeBench、四个编码代理，以及相同 LLM 和评估协议下与 Claude Code、OpenHands 的比较，不能据此确认其他数据集、模型或实际开发环境中的效果。摘要未明确陈述方法自身的限制，也未提供统计显著性、误差或置信区间、消融实验、稳定行为差异的具体判定标准，以及对最终代码行为符合用户意图程度、开发中断或纠正成本的直接量化验证信息。作者称已实现插件，但其公开可获取性、代码开放情况和复现条件未知；这些信息缺失不代表研究本身未开展相关验证。
