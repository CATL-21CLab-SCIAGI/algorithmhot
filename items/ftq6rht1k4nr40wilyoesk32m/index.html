研究发现 AppWorld 与 WorkArena 任务验证器的判定盲点

Finding Blind Spots in AppWorld and WorkArena Task Verifiers

AI 导读

研究通过源码引导的变异测试，报告 AppWorld 与 WorkArena 原有任务验证器会将部分错误结果判为成功。AppWorld 中，重复非幂等写入产生额外记录却保持所有受检字段值不变，5个符合条件的生成器中有2个的全部3种任务变体获通过，共6/15个构造效果；事后在验证器副本中增加记录数量检查，使这6例均被拒绝，有效对照仍通过。

基于摘要arXiv:2610.09142v1
研究变化
作者采用利用验证器源码信息设计的变异测试，审计已交付的 AppWorld 和 WorkArena 执行式任务验证器，检验其是否会把产生错误实际效果的代理执行判为成功。主审计不修改原有检查器。AppWorld 的构造重复执行非幂等写入，在保持所有被检查字段值不变的同时增加一条记录；WorkArena 的构造检验额外字段写入，并通过独立的 Table API 回读确认实际持久化效果。作者还使用固定的意图交换网格考察检查器的拒绝行为。完成 AppWorld 枚举审计后，作者在检查器副本上加入记录数量检查补丁，验证能否拒绝已发现的错误效果并保留有效对照。
适用任务
当前资料支持的范围是 AppWorld 与 WorkArena 中依靠执行后状态判断代理任务是否成功的验证器审计。具体对象包括 AppWorld 非幂等写入造成额外记录但被检查字段不变的情形、WorkArena 表单额外字段的持久化修改，以及固定意图交换网格中的非对角执行。作者报告的 WorkArena 已确认错误效果覆盖 3 种表单模板。对其他平台、验证器、任务类型或模型的适用性未知：当前资料未提供。
作者报告的比较条件
AppWorld：作者报告，在 5 个符合条件的生成器中，2 个生成器各自的全部 3 个任务变体均被接受，即 15 个构造效果中有 6 个被接受（6/15）。枚举审计结束后，在检查器副本上应用记录数量补丁，使这 6 个测试单元全部未通过，同时有效对照仍通过；有效对照数量未知。WorkArena：作者对因先前检查器结果为 PASS 而筛选出的 23 个额外字段候选进行前瞻性重跑，全部 23 个仍获 PASS。独立 Table API 回读确认其中 21 个持久化了非默认值，另有 2 个请求字符串是已存储默认值的别名；21 个已确认错误效果跨越 3 种表单模板。这是经筛选案例的结果，不能据此估计总体错误接受率。作者报告，其他构造均未产生经独立确认的错误接受；其余检查器 PASS 案例属于效果正确的退化情形。固定意图交换网格：2,689 次非对角执行中没有 PASS；其中 57 个 WorkArena 单元使用会话范围证据，其余 2,632 个缺少已分类的拒绝原因及独立的目标真值。作者因保留证据不同而单独报告零 PASS 测试族，并称每个增量均在其自身测试单元评分前确定。报告指标是 PASS、未通过及实际效果确认的计数，单位为构造效果、候选、测试单元或执行次数；未报告速度或质量增益。完整数据规模、任务总数、模型名称与数量、硬件、计算预算、运行时长及其他计算设置未知：当前资料未提供。
证据限制
证据仅为用户提供的摘要，未核对全文或补充材料；上述结果均属于作者报告，不是本次独立复现。WorkArena 的 23 个候选按先前 PASS 结果筛选，作者明确限定其只能确认审计协议下的错误效果，不能估计总体发生率。Table API 独立回读是作者审计中的效果核验，不等于外部团队独立复现。2,689 次执行的零 PASS 结果属于拒绝枚举，不能直接视为 2,689 次均已独立确认正确拒绝；57 个单元的证据限于会话范围，其余 2,632 个缺少拒绝原因分类和独立目标真值。AppWorld 补丁结果限于检查器副本、所报告的 6 个单元及有效对照，摘要未提供更广泛验证。作者称 OpenReview 投稿附有补充材料，包含构造语法、证据、与内容绑定的阶段谱系及计数复现器；当前未访问这些材料，不能据此确认代码公开可用或结果已被独立复现。摘要未提供的详细协议、统计不确定性和跨平台泛化验证均保持未知，不能据此断言研究本身不存在这些信息。
