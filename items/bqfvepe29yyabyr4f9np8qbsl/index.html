研究报告输入无关对照在层执行程序的多项选择评测中也产生可观的理想择优增益

Input-Blind Controls Produce Substantial Oracle Headroom for Layer Programs in Multiple-Choice Evaluation

AI 导读

研究报告，多项选择评测中的输入无关对照也能获得较大的 oracle 理想择优增益，跨提示保留的增益不足以单独确立所选层计算的特定收益。根据当前材料，研究在 Qwen3-4B-Base 和 Llama-3.1-8B 的 4,413 道题上比较了 32 种层跳过与重复执行程序及同位置的扰动对照，以不使用评测提示选出的固定操作为基准，并在另一提示上重新评估选择结果。

基于摘要arXiv:2610.10368v1
研究变化
作者研究自适应语言模型推理中的层跳过与层重复程序，重点区分两个问题：利用已知答案的 oracle 评估能否显示选择程序的潜在增益，以及该增益能否归因于所选层计算本身。作者将真实层程序相对固定动作的增益，与相同干预位置上的输入无关扰动对照进行比较；固定动作在不使用评估提示的情况下选出，选择结果再用另一提示重新评估。分析还包括改变选项排列、固定答案字母偏移、较小规模的 KL 校准比较及补充生成答案测试。这一设计旨在检验：跨提示保留的选择增益，是否足以证明特定层计算的益处，而非直接提出一个已验证的实用选择器。
适用任务
当前摘要支持的研究范围是语言模型自适应推理的 oracle 潜力评估与对照分析，干预对象为层跳过和层重复程序。主要实验覆盖 Qwen3-4B-Base 与 Llama-3.1-8B 两个模型上的多项选择题，并考察跨提示重新评估及选项顺序变化。补充实验涉及生成答案任务中，搜索选出的程序在问题改写后能否保留优势。对其他模型、任务、实际部署或推理加速的适用性未知：当前资料未提供。
作者报告的比较条件
作者报告主要分析使用 32 个层跳过与层重复程序、两个模型和 4,413 道多项选择题；程序在不同模型及干预类型间的分配、数据集名称和题目构成未知。比较基准是未使用评估提示选出的固定动作，对照是在相同位置施加的输入无关扰动，并在另一提示上重新评估选择结果。共享选项顺序时，Qwen3-4B-Base 上对照的潜在提升空间（headroom）为 10.2–11.8 个百分点，真实程序为 9.0 个百分点；Llama-3.1-8B 上分别为 15.6–19.4 和 10.1 个百分点。每个模型均有三次随机方向抽样，三次中对照均超过真实程序；这些范围不是普遍增益或平均增益。上述对照仅匹配答案改变率。排序依赖候选程序集合：在事后分析的 Llama 仅重复层集合中，真实程序在每次抽样中均领先。较小规模的 KL 校准比较包含一个输入相关对照，点估计有利于真实程序，但校正后的检验未得出明确结论；该比较的样本量、效应数值和检验细节未知。固定答案字母偏移产生了相近量级的潜在提升空间，具体数值未知。轮换选项排列显著降低真实程序与对照两类的潜在提升空间，但真实程序减去对照仍为正：Qwen3-4B-Base 为 1.4–2.3 个百分点，Llama-3.1-8B 为 3.7–4.5 个百分点；差值大小及统计支持取决于进一步调整和所用参照。补充生成答案测试中，搜索选出的程序在问题改写后，相对为其他问题选出的程序仍保留 26.0 个百分点的优势，但未设置安慰剂对照。硬件、运行精度、批量大小、计算预算、搜索成本、延迟或吞吐量，以及补充测试的数据量、模型配置和各指标的完整计算定义均未知：当前资料未提供。
证据限制
证据仅来自所提供摘要，未核对全文；所有结果均为作者报告，当前资料未提供独立复现证据。作者明确指出，共享选项顺序时，较大的潜在提升空间可跨提示保留，但这并不能证明所选层计算具有特有益处；无论真实程序相对这些对照领先还是落后，都不能单凭该排序识别这种益处。主要扰动对照仅匹配答案改变率，结论受候选程序集合影响，且仅重复层集合的比较属于事后分析。较小规模 KL 校准比较的点估计偏向真实程序，但校正检验结论不明确。选项轮换后的差异大小与统计支持依赖进一步调整和参照。生成答案补充实验缺少安慰剂对照，因此其 26.0 个百分点优势也不能单独确立层计算特有的收益。摘要未给出置信区间、具体显著性检验结果、完整实验配置、实用选择器的性能验证或实现可用性信息；这些信息缺失不表示研究本身不存在相关材料。
