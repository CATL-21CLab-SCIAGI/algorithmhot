Task Vector Descent：从非独立同分布批次中学习

Task Vector Descent: Learning from Non-IID Batches

AI 导读

Task Vector Descent 研究提出部分整合非独立同分布训练中的任务向量，作者报告这常能改善持续训练模型的平均表现。方法将连续同分布训练产生的参数位移与优化器状态按相同系数 λ 缩放，以 λ=1 的完整整合作为比较基线。

基于摘要arXiv:2610.05402v1
研究变化
作者针对持续学习中学习新知识与保留已有知识之间的稳定性—可塑性权衡，提出部分整合任务向量：将连续训练序列产生的参数位移（task vector）乘以系数 λ，再应用于继续训练的模型，同时将优化器状态乘以同一系数。比较基线为完整保留参数位移，即 λ=1。作者报告，当训练数据按分布在时间上聚集时，适应当前分布可能改善该分布上的表现，却使先前训练数据上的表现下降；连续接触同一分布的时间越长，这种权衡越强。该方法考察是否应仅保留部分参数位移，以改善继续训练模型的平均表现。
适用任务
资料涉及语言模型训练中来自不同领域、用户或任务的数据分布随时间不均衡出现的情形：相邻 minibatch 按分布在时间上聚集，而非从整体数据混合中独立同分布采样。作者报告的实验覆盖4类训练场景：持续预训练、从随机初始化开始的预训练、监督后训练和强化后训练。其中持续预训练包含受控数据流与自然定义的适应序列。具体语言、领域、数据集、模型架构与规模，以及对其他对象的适用性，当前资料未提供。
作者报告的比较条件
作者比较完整整合（λ=1）与采用中间 λ 值的部分整合，后者同时缩放任务向量和优化器状态。作者报告，在上述4类训练场景中，中间 λ 值相较完整整合往往能改善继续训练模型的平均表现，尤其在较长的同分布连续训练序列之后；这不是所有条件均改善的结论。在持续预训练的受控数据流和自然定义的适应序列实验中，作者报告，任务向量缩放在相同学习率下优于完整整合，其收益不能仅由学习率缩放重现。摘要未给出具体 λ 中间值、学习率数值或调度、序列长度、数据量、数据集数量、模型数量、具体任务数量、实验次数、硬件、优化器类型及其余计算设置。结果仅以平均表现和相对优劣描述；具体指标定义、平均的分母与权重、单位、绝对结果和提升幅度均未知。
证据限制
证据仅为用户提供的摘要，未核对全文，也未进行独立复现；所有实验观察和比较结论均为作者报告。摘要以‘往往改善’限定部分整合的效果，并强调较长同分布序列后的改善；关于相同学习率下的优势及学习率缩放不能重现收益的结论，明确对应所述持续预训练实验。摘要未提供各场景的逐项结果、性能下降或无改善条件、统计不确定性、重复运行信息，也未提供分别量化当前分布适应能力与既有知识保留程度的验证细节。除这些结果限定外，作者明确陈述的其他方法限制未知。代码、开放实现及独立验证信息未知：当前资料未提供，不能据此断言研究本身没有这些内容。
