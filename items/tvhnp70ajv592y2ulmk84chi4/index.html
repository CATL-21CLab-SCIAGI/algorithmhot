HC-DLM 提出分层连续扩散语言模型，耦合 token 生成与潜变量更新

Hierarchical Continuous Diffusion Language Models

arXiv · AI 与机器学习发表 2026-10-02 01:59 北京时间查看原文 ↗
基于摘要作者报告 · 独立复现未核验

HC-DLM 研究提出分层连续扩散语言模型，将离散 token 生成与连续潜变量轨迹耦合在同一去噪过程中。根据当前材料，连续潜变量是唯一持久的生成状态，每一步从中读出 token 并反馈以辅助下一次潜变量更新，训练目标由 token 似然的变分界推导。

研究变化

作者提出分层连续扩散语言模型（Hierarchical Continuous Diffusion Language Models，HC-DLM），在同一去噪过程中耦合离散词元生成与连续潜变量轨迹，训练目标由词元似然的变分界推导。其针对两类问题：离散扩散语言模型并行解码时，各词元从各自边缘分布独立采样，切断同时解码词元间的统计依赖；连续扩散语言模型虽通过共享连续状态去噪，但去噪器仅观察该状态，直到最终解码才与有效词元配置建立联系。不同于在独立运行的离散链上附加连续上下文的方法，HC-DLM将潜变量作为唯一持续保留的生成状态，每一步从中读出词元，再将词元反馈为下一次潜变量更新的支架。

适用任务

摘要支持的评估范围包括3类任务及对应对象：结构化推理（Sudoku，数独）、数学规划（Countdown）和语言建模（LM1B）。作者将离散扩散语言模型描述为适合需要双向推理与全局约束满足的任务的候选方案，但当前资料仅报告HC-DLM在上述3个对象上的评估，其他任务与对象上的适用效果未知。

作者报告的比较条件

作者报告，在模型规模匹配的条件下，HC-DLM优于离散扩散和连续扩散基线：Sudoku与Countdown上的谜题准确率提高，LM1B上的生成困惑度改善。摘要列出3个评估对象，未给出各对象的样本数、划分、难度或预处理设置。具体基线名称、基线模型数量、模型参数量、训练与推理计算预算、硬件、解码步数和采样设置均未知。指标为谜题准确率与生成困惑度；数值、报告单位、提升幅度、统计汇总口径、准确率分母及不确定性均未知。摘要未提供可量化的最高或平均增益。
