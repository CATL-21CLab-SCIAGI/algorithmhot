GLHF 为基于偏好的对齐提供分组失真保证

Groupwise Distortion Guarantees for Preference-Based Alignment

AI 导读

研究提出 GLHF，用每位用户一次偏好比较学习按群体条件化的单一 LLM 策略，并给出分组失真保证。根据当前材料，失真指最优固定回答分布与所学分布的社会福利之比的最坏情况，社会福利指平均基数效用。

基于摘要arXiv:2610.05450v1
研究变化
作者提出高效算法 GLHF：利用每名用户的一次成对比较，学习一个按群体条件化的策略，使不同用户可以接收不同的响应概率分布（lottery）。它针对的问题是：RLHF、NLHF 等方法通过成对偏好学习策略，但仅凭比较未必能识别最大化社会福利（平均基数效用）的策略；摘要引用的 GHY 结果虽表明 NLHF 在所有用户接收同一分布时最优，但账户型 LLM 掌握用户信息，可以采用差异化分布。作者将保证扩展到预先指定、可能相互重叠的用户群体。
适用任务
资料支持的目标任务是基于成对偏好的 LLM 对齐，尤其是利用账户用户信息、按群体提供响应分布并改善各群体社会福利的场景。理论针对预先指定且可能重叠的群体集合，并以个体 Bradley–Terry 比较模型为条件；偏好相似的群体另有更紧保证。实验材料包括人类咖啡评分和由 LLM 生成的合成评分。具体 LLM 下游任务、领域覆盖及实际部署范围未知：当前资料未提供。
作者报告的比较条件
理论比较基准是摘要引用的 Gölz、Haghtalab 和 Yang（GHY）的最优总体 distortion 界，以及其在所有用户接收同一响应分布时关于 NLHF 最优性的结果。distortion 定义为最佳固定响应分布的社会福利与所学响应分布的社会福利之比的最坏情况值，是无量纲比值；社会福利指平均基数效用，原始评分或效用的单位未知。作者报告，在个体 Bradley–Terry 比较条件下，GLHF 使用每名用户一次比较，渐近地同时在预设集合中的每个群体上达到 GHY 的最优总体 distortion 界；样本复杂度随群体数量的对数增长，并与最小群体所占比例成反比。对于偏好相似的群体，作者给出更紧保证：当成员共享一个可行的最偏好响应时，distortion 趋近于 1。实验使用人类咖啡评分和 LLM 生成的合成评分，比较对象为 NLHF 及其他不区分群体的基线；RLHF 在摘要中是背景方法，未明确列为实验比较对象。作者报告 GLHF 在每个被评估群体中降低 distortion，并相对上述基线大幅降低最差群体的 distortion。具体数值、绝对或相对降幅、最优总体界的公式均未知；数据集、模型、任务、群体、用户及响应的具体数量，以及硬件、运行时间、训练配置和计算预算也未知：当前资料未提供。
证据限制
证据仅为所提供的摘要，未核对全文；理论与实验结论均为作者报告，不能视为独立复现。摘要明确指出，仅凭成对比较未必能识别社会福利最大化目标。GLHF 的主要理论保证依赖个体 Bradley–Terry 比较、预先指定的群体集合，并采用渐近口径；不能据此认定任意有限样本或任意偏好机制下都达到同样的界。样本复杂度对最小群体占比的依赖意味着占比越小，所述样本需求越高；趋近 distortion 为 1 的更紧保证具有共享可行最偏好响应等条件，不能推广到任意群体。实验结论限于摘要所述评分材料和被评估群体，未提供具体实验设计、误差或置信区间、统计检验、重复次数、评分生成模型细节及真实账户型 LLM 部署验证。当前资料也未提供代码、数据开放情况或独立复现信息；这些缺失不代表研究本身不存在相应材料。
