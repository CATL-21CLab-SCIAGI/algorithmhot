贝叶斯充分压缩仍不够：通信如何帮助多智能体系统？

Bayes-Sufficient Compression Is Not Enough: How Does Communication Help Multi-Agent Systems?

AI 导读

该研究提出接收方相对的有界协调框架，分析多智能体 LLM 系统中短消息、原始上下文与更强发送方何时有助于执行方决策。根据当前材料，作者将消息效用表示为接收方收益减去协议开销，并指出即使压缩满足贝叶斯充分性，能力受限的执行方仍可能无法利用其表达形式；外化、吸收与行动闭合的三阶段分解用于解释正确内容送达后仍残留的错误。

基于摘要arXiv:2610.03769v1
研究变化
作者提出“相对于接收者的有界协调”（receiver-relative bounded coordination）框架，研究在发送者拥有广泛上下文、执行者仅有有限局部视野的多智能体 LLM 系统中，短消息何时能改善执行者的下一步决策、何时原始上下文更合适，以及何时增强发送者有帮助。框架将消息效用表示为接收者增益减去协议开销：只有当开销节省超过信息省略和解码器不匹配造成的损失时，压缩才优于原始上下文。作者指出，即使压缩具有贝叶斯充分性，受限执行者也可能因无法利用其表面表达形式而失败。作者进一步将过程分为外化、吸收与行动闭合三个阶段，用于解释正确内容到达接收者后仍然出现的错误；在单交叉条件下，增强发送者在接收者负担超过某个阈值时才有帮助。作者据此设计推理时选择器，并报告其改善了所评估通信条件下的准确率—成本前沿。
适用任务
资料支持的对象是由广泛上下文发送者与局部视野受限执行者组成的多智能体 LLM 系统，关注通信后执行者的下一步决策。适用问题包括压缩消息与原始上下文的选择、增强发送者是否有益的判断，以及正确内容传达后仍未转化为正确行动的故障分析。作者在六个基准上开展评估，摘要仅明确点名 ContextBench 和 ToolSandbox；其余基准名称、具体任务构成及更广泛的适用范围未知。推理时选择器的效果仅被报告于已评估的通信条件。
作者报告的比较条件
作者报告在六个基准上的评估结果：同一 Qwen 协议使 ContextBench 的联合准确率从 0.633 升至 0.775，但使 ToolSandbox 的准确率从 0.889 降至 0.653。上述数值按摘要中的准确率小数原样保留；摘要未明确 ToolSandbox 是否也采用联合准确率口径，也未说明这些变化所对应的具体基线配置。研究讨论的比较包括短消息与原始上下文、以及增强发送者的效果，但摘要没有给出各项比较的完整实验配置或全部结果。作者还通过固定消息重放观察到：即使正确恢复了工件，仍会发生行动闭合失败。作者报告推理时选择器改善准确率—成本前沿，但未给出其具体增益、成本数值或成本单位。已知基准总数为六；数据集样本量、任务总数、模型数量、Qwen 具体型号与规模、发送者和执行者的模型配置、硬件、计算预算、消息长度、推理参数、重复次数、统计不确定性、指标分母及其余基准结果均未知：当前资料未提供。
证据限制
当前证据仅为摘要，未核对全文；所有理论结论与实验结果均为作者报告，当前资料不构成独立复现证据。作者明确指出，压缩可能因信息省略、解码器不匹配及执行者对表达形式的利用能力受限而失效，贝叶斯充分性本身不能保证有效；正确内容到达或工件被正确恢复也不能保证行动闭合。增强发送者的阈值结论以单交叉条件为前提，摘要未提供该条件的形式化定义、阈值数值或实际判定方法。同一 Qwen 协议在两个已披露基准上效果方向相反，因此不能将其中的提升推广为普遍收益。选择器的改善仅限作者所评估的通信条件，摘要未提供具体收益幅度及跨条件泛化验证信息。完整实验配置、统计检验、全部基准结果、实现开放情况和独立复现情况均未知：当前资料未提供；这些信息缺失不等于研究本身不存在相应工作。
