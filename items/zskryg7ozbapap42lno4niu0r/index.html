GALA 提出高斯混合形状蒸馏方法，加速实时虚拟化身动画

One Basis to Animate Them All: Gaussian Blendshape Distillation for Real-Time Avatars

arXiv · AI 与机器学习发表 2026-10-02 01:59 北京时间查看原文 ↗
基于摘要作者报告 · 独立复现未核验

GALA 研究提出以浅层系数预测器和线性混合替代逐帧重型神经解码，作者报告可显著降低高斯虚拟化身的动画计算成本。根据当前材料，该方法在渲染感知度量与内存预算约束下，通过分块局部 PCA 构建不依赖身份的混合形状基，无需重新训练原始模型。

研究变化

作者提出 GALA（Gaussian Animation via Linear Approximation）蒸馏方法，针对 3D Gaussian 化身虽可快速渲染、但逐帧神经网络推理成本阻碍实时动画的问题。作者报告，预训练化身模型的动画可由身份无关的混合形状（blendshapes）线性组合近似，因此用浅层 MLP 预测混合形状系数，再进行线性混合，替代逐帧繁重的神经解码。为提高保真度并降低内存需求，作者在渲染感知度量和内存预算约束下采用分块局部 PCA 构建基底。该方法适配多种动画架构，无需重新训练原始模型。

适用任务

摘要支持的任务为预训练 3D Gaussian 化身模型的动画推理加速，涵盖面部表情动画，以及带服装动态的全身动画。作者在 3 个不同的化身模型上验证方法，并报告蒸馏结果可泛化至留出的身份。摘要还报告移动设备上的动画运行结果；具体设备、适配架构名称及更广泛适用范围未知。

作者报告的比较条件

作者报告通过蒸馏加速 3 个不同化身模型的推理，比较语境为原始模型的繁重神经解码与 GALA 的浅层系数预测及线性混合；模型名称、版本及其他比较方法未知。验证涵盖面部表情和带服装动态的全身动画，但具体任务实例数、数据集、身份数量、样本量及划分比例未提供。作者报告，在这些模型上，CPU 动画计算成本最多降低 3 个数量级，同时保留大部分渲染质量；这属于最高降幅口径，不能理解为每个模型或平均均达到该降幅。原始及加速后的绝对成本、成本的具体计量方式与单位、逐模型结果均未知。作者另报告移动设备上的帧率最高达到 60 fps（帧/秒）；该最高帧率对应的模型、任务、设备与测量范围未提供，不能与 CPU 成本降幅视为同一测试条件。CPU 型号、移动设备型号、渲染分辨率、并行与批量设置、内存预算数值、训练或蒸馏计算配置、渲染质量指标及数值均未知。

证据限制

当前证据仅为摘要，未核对全文，也无独立复现证据。加速、质量保留、留出身份泛化及最高移动端帧率均为作者报告。摘要使用‘近似’与‘保留大部分渲染质量’的表述，不支持无损或完全等价的结论；具体质量损失、失败情形和误差分布未知。作者将结果解释为支持所学化身表示具有共享线性结构，但当前资料未提供可独立核验这一解释的详细实验。摘要未明确列出其他限制，也未提供统计不确定性、消融实验、内存节省幅度或更广泛模型与设备验证的信息，不能据此断言这些研究或验证不存在。资料给出了项目页面链接，但不足以确认代码、模型或数据已开放，也不构成独立复现。
