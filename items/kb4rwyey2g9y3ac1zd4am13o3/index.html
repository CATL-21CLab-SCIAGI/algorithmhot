ProsaBuddy：用 LLM 智能体辅助实时系统可调度性的机械化证明

ProsaBuddy: Assisting Mechanized Real-Time Schedulability Analysis with LLM-based Agents

AI 导读

ProsaBuddy 研究提出面向实时系统可调度性证明的 LLM 智能体系统，旨在降低构建机械化证明所需的工作量。根据当前材料，该系统通过 ReAct 循环检索 Prosa 代码库、调用 Rocq 工具并接受可选的人工提示，将引理拆成子目标后交给子智能体证明。

基于摘要arXiv:2610.03796v1
研究变化
作者提出基于大语言模型的代理系统 ProsaBuddy，以降低在 Rocq 证明助手中开发机械化实时可调度性证明所需的时间与专业知识门槛。其方法结合 ReAct 循环、对 Prosa 代码库的检索、Rocq 工具访问及可选的人工提示，并采用子目标委派架构，将引理分解为子目标，再交由子代理证明。研究背景是硬实时系统需要严格的可调度性分析，而纸笔证明中的错误可能威胁关键应用的安全。
适用任务
资料支持的任务是在 Prosa 基础上、使用 Rocq 开发可由机器检查的实时可调度性证明，包括引理的子目标分解与证明。作者在一个取自实时调度文献的小型基准上进行了评估。具体调度模型、系统类型、引理类别及对其他证明领域的适用范围未知：当前资料未提供。
作者报告的比较条件
作者报告的比较对象包括被其称为当前最先进的、基于大语言模型的 Rocq 自动证明代理系统，以及通用编码代理 OpenCode；摘要未列出前一类系统的具体名称或数量。评估使用一个取自实时调度文献的小型基准，基准中的任务、引理或样本数量，以及所用大语言模型的名称和数量均未知。作者称 ProsaBuddy 的表现显著优于上述比较对象，但当前摘要未提供指标名称、单位、绝对结果、增益数值、最高或平均口径、成功率分母或统计显著性检验信息。硬件、计算与时间预算、重复实验次数，以及各比较对象的检索、工具和人工提示配置均未知。方法允许使用可选人工提示，但实验是否使用提示及如何控制比较条件，当前资料未提供。
证据限制
当前证据仅为摘要，未核对全文。优于比较对象的结论属于作者报告，当前资料不构成独立复现证据。评估证据限于摘要所述、取自实时调度文献的小型基准，不能据此确定对更广泛任务或实际硬实时系统的泛化效果，也不能推断已验证安全性提升或开发时间的具体降幅。作者明确指出构建 Prosa 机械化证明耗时且需要较多专业知识，这是研究动机；摘要未明确陈述 ProsaBuddy 自身的局限。完整实验设置、定量结果、消融实验、失败案例、人工提示的影响、生成证明的逐项检查结果，以及代码与基准的开放情况均未知：当前资料未提供；不能据此断言研究本身没有这些信息。
