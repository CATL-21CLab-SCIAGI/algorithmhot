sk-bench 研究提出原生数据优先的斯洛伐克语 LLM 评测基准

sk-bench: A Native-First Benchmark for Evaluating Large Language Models in Slovak

AI 导读

sk-bench 研究提出原生数据优先的斯洛伐克语 LLM 评测基准，包含 30 个数据集、33 个计分任务变体，覆盖十类能力。根据当前材料，作者在统一框架下评测了 55 个开放权重与闭源权重模型，报告最佳开放模型落后专有 API 12.6 分。

基于摘要arXiv:2610.09152v1
研究变化
作者提出 sk-bench，一个原生数据优先的斯洛伐克语基准，旨在解决现有多语言 LLM 基准遗漏斯洛伐克语，或仅通过机器翻译覆盖该语言的问题。斯洛伐克语是一种形态丰富、约有五百万使用者的西斯拉夫语言。该基准包含 30 个数据集、33 个计分任务变体，覆盖十类能力；其中 11 项资源是新引入或首次被整理用于生成式 LLM 评测，包括配备斯洛伐克语适配指令检查器的 IFEval-SK，以及用于斯洛伐克语语法和形态评测的原生 Chiby/SKJ1 资源。作者在统一评测框架下评估模型，并比较数据来源、语言适应训练及测试时推理对结果的影响。
适用任务
资料支持的范围是生成式 LLM 的斯洛伐克语能力评测，涉及开放权重与封闭权重模型。摘要明确涉及指令遵循、斯洛伐克语语法与形态、封闭式（closed-form）任务和问答；十类能力的完整清单未知。作者还据此为其他低资源语言提出四条设计建议：在翻译失效的场景使用原生数据；语言适应后规划指令能力修复；扩大模型规模前先启用测试时推理；避免对目标语言提示投入过多。摘要未提供这些建议在其他语言上的验证。
作者报告的比较条件
作者报告在同一评测框架下评估 55 个开放权重和封闭权重模型，基准规模为 30 个数据集、33 个计分任务变体、十类能力。最佳开放模型落后于专有 API 模型 12.6 个分数点；具体模型名称、对应 API 比较对象及分数尺度未知。原生与翻译的封闭式数据所得模型排名相似，相关系数 ρ≥0.98，但翻译数据对最强模型的区分能力较弱；人工编写与 LLM 生成的问答问题所得模型排名存在差异，ρ=0.72。ρ 的具体计算定义及各项相关性比较纳入的模型数量未知。对 Qwen3-14B，继续进行斯洛伐克语预训练使总体分数下降 13.9 个分数点；一个小规模指令集恢复了这部分损失的四分之三，该比例的分母是此前的分数损失。对于 9B 及以上规模的模型，测试时推理使分数提高 8.5 至 12.5 个分数点；这是作者报告的区间，不能视为所有模型的普遍增益或平均增益。摘要未提供该项比较的具体模型名单和数量、区间端点对应条件。硬件、计算预算、训练与推理配置、提示设置、指令集规模、各数据集样本数、评分归一化尺度及总体分数聚合方式均未知；上述分数点不能直接换写为百分比提升。
证据限制
当前证据仅为摘要，未核对全文；全部实验结果均为作者报告，并非独立复现。作者报告的限制性发现包括：翻译数据较难区分最强模型，人工与 LLM 生成问答会产生不同排名，以及 Qwen3-14B 的斯洛伐克语继续预训练在所测条件下导致总体分数下降。上述结果不能外推为所有任务、模型或语言都具有相同表现；原生与翻译封闭式数据的高排名相关性，也不能证明两者在其他评测方面等价。摘要未提供完整任务与模型清单、逐项结果、统计不确定性、重复运行信息及详细实验设置，因此目前无法据此核查结果的稳健性或可复现性。作者声明在 https://github.com/slovak-nlp/sk-bench 发布数据与代码；当前资料仅提供这一声明和链接，未验证仓库可访问性、实现完整性、数据许可或独立复现情况。
