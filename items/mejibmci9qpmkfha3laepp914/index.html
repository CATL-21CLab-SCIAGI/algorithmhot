AlignQuant 提出面向高效 LLM 生成的分块对齐混合精度量化方法

AlignQuant: Tile-Aligned Mixed-Precision Quantization for Efficient LLM Generation

AI 导读

AlignQuant 提出分块对齐的训练后混合精度量化方法，以 GPU 兼容的二维权重块统一精度分配、紧凑存储与执行。该方法联合校准 prefill/decode，在模型级权重存储预算内为任一阶段的重要分块保留较高精度，并将低比特权重展开后配合 8-bit 激活执行 INT8 计算。

基于摘要arXiv:2610.07457v1
研究变化
作者提出训练后量化方法 AlignQuant，针对细粒度混合精度的局部精度选择与 GPU 规则存储、计算单元之间的精度边界不匹配问题，旨在使压缩更有效地转化为实际加速。方法以 GPU 兼容的二维权重分块作为精度分配、紧凑存储和执行的共同单元，使精度能够随输出通道内部的敏感性变化。联合 prefill（预填充）与 decode（解码）校准，在量化激活条件下，以语言模型损失梯度加权投影输出扰动，评估降低精度的影响；经阶段归一化的评分在全模型权重存储预算下，优先为对任一阶段重要的分块分配更高精度。每个分块仅存储一种选定表示，阶段专用内核复用同一份打包模型，将低比特权重展开用于 INT8 计算，激活为 8 位。
适用任务
当前摘要支持的范围是大语言模型的训练后细粒度混合精度权重量化与推理加速，涉及预填充、解码及文本生成。作者报告评估覆盖 4 个大语言模型，参数规模为 3B 至 14B，并覆盖 3 款 GPU 和最长 64K tokens 的上下文。具体模型名称、任务类别与任务数量未知：当前资料未提供。
作者报告的比较条件
作者报告：在参数规模为 3B 至 14B 的 4 个大语言模型评估中，相对 BF16，AlignQuant 的生成加速比最高达到 2.50×，同时保持模型质量；这是最高加速比，摘要未给出平均值、各模型结果或达到最高值的具体配置。评估另覆盖 3 款 GPU，以及最长 64K tokens 的上下文，但未说明这些条件是否均对应 2.50× 加速，也未给出模型、GPU 与上下文的完整组合结果。明确的计算设置包括 INT8 计算、8 位激活、全模型权重存储预算，以及预填充和解码专用内核复用打包模型。GPU 型号、软件环境、批大小、输入与输出长度、具体上下文测试点、权重候选位宽、存储预算数值、数据集及其数量、任务数量、校准数据与规模、BF16 基线实现均未知。性能指标仅提供相对 BF16 的生成加速倍数，未提供绝对延迟、吞吐量或其单位；模型质量的指标、数值及变化幅度未知。其他比较方法与结果未知：当前资料未提供。
证据限制
证据仅为用户提供的摘要，未核对全文、表格或补充材料。加速与质量保持均为作者报告，当前资料不含独立复现证据；无法由最高 2.50× 推断所有模型、GPU 或上下文均获得该增益，也无法定量判断质量保持程度。摘要未明确陈述 AlignQuant 自身的局限；其指出的精度边界不匹配是方法试图解决的问题，不能据此认定该问题已在所有场景消除。误差范围、重复实验、统计不确定性、消融实验及评估范围外的泛化验证信息未知：当前资料未提供，不能据此断言研究本身未开展这些验证。作者称实现位于 https://github.com/HanzhiZhang-Ulrica/AlignQuant，但链接未访问，代码可用性、完整性及可复现性均未验证。
