KaliBench 研究提出面向 Kali Linux 安全工具调用的细粒度基准与免运行可验证奖励

KaliBench: A Fine-Grained Benchmark for Cybersecurity Tool Use on Kali Linux with Runtime-Free Verifiable Rewards

AI 导读

KaliBench 研究提出面向 Kali Linux 的自然语言到命令行翻译基准，用于评估 LLM 的工具选择与参数构造能力。根据当前材料，数据集包含 8,504 个查询—命令对，覆盖 1,642 个工具、23 个能力维度和 5 个安全阶段，采用确定性规范化与别名感知评估，并结合 LLM 验证、沙箱终端执行和人工参与改进进行多阶段验证。

基于摘要arXiv:2610.02206v1
研究变化
作者提出 KaliBench：面向 Kali Linux 的自然语言到命令行接口（CLI）翻译的细粒度基准与数据集，针对现有知识型评测或端到端智能体任务不能直接衡量模型为真实网络安全工具生成可执行命令的能力这一缺口。具体关注工具选择与参数构造，以及微小语法错误、标志与值绑定错误、参数顺序错误导致命令无法执行的问题。作者采用以文稿为依据的构建流程、确定性规范化和别名感知评测，并结合 LLM 验证、沙箱终端执行及人工参与修订开展多阶段验证，以支持语义正确性与实际可执行性检查。作者进一步利用细粒度、确定性的评测信号，为训练提供无需运行时执行的可验证奖励。
适用任务
资料支持的任务是将分析人员的自然语言意图转化为 Kali Linux 网络安全工具命令，评估工具选择和参数构造能力，并支持监督微调及使用可验证奖励的强化学习。数据集包含 8,504 个查询—命令对，覆盖 1,642 个工具、23 个能力维度和 5 个安全阶段。作者评测了通用及安全领域的开放权重模型。具体工具清单、能力维度和安全阶段名称，以及对其他操作系统或完整网络安全工作流的适用性，当前资料未提供。
作者报告的比较条件
作者报告在 3 种评测模式下评测了通用及安全领域开放权重模型的 24 种配置；24 指配置数量，不能据此确定独立模型数量。数据集总规模为 8,504 个查询—命令对，覆盖 1,642 个工具、23 个能力维度和 5 个安全阶段，但评测样本量、训练与测试划分及各模式的样本分母未知。在不受限制、没有显式工具提示的设置下，作者报告所评测的开放权重模型均未超过 42% 的精确命令准确率；这一结论不能外推至其他模式或所有模型。作者还报告，通过监督微调及基于 KaliBench 可验证奖励的强化学习，一个 8B 模型得到显著改善，并达到与一个 685B MoE 模型相当的表现；8B 和 685B 分别为约 80 亿和 6,850 亿参数的规模表述，摘要未说明 MoE 的总参数与激活参数口径。具体模型名称、另外两种评测模式的定义、训练前后分数、提升幅度、相当表现对应的指标与条件、统计显著性检验、硬件、计算预算及训练超参数均未知：当前资料未提供。
证据限制
当前证据仅为摘要，未核对全文。上述数据规模、验证流程、准确率上限及训练改善均为作者报告，当前资料不包含独立复现证据。摘要指出，在无显式工具提示时准确使用网络安全 CLI 仍然困难；42% 的结果仅适用于作者所报告的不受限制设置及所评测开放权重模型。摘要未提供各工具、能力维度或安全阶段的分项结果，也未提供语义正确性、沙箱可执行性及人工修订的具体覆盖率、通过率或一致性信息。作者将评测描述为精确且可复现，但当前资料未提供可核查的完整实验设置、代码或数据获取信息，不能据此确认开放实现或独立可复现性。训练后与 685B MoE 模型表现相当的结论缺少具体分数与比较细节，不能推断全面能力相当或计算成本优势。
