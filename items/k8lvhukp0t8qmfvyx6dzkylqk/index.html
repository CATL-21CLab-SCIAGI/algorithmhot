LADE 研究提出利用暗知识中的模型无关潜在安全信号保护 LLM

Safeguarding LLMs via Model-Agnostic Latent Safety Signals from Dark Knowledge

AI 导读

LADE 研究提出从 LLM 首个 token 的输出概率分布中提取潜在安全信号，以模型无关的方式识别有害查询并防御攻击。该方法利用暗知识，即输出概率分布中超出 argmax 结果的信息，筛选有害与良性查询间概率差异明显的 top-k token，并通过跨分词器映射和 kNN 分类查询。

基于摘要arXiv:2610.07532v1
研究变化
作者提出 LADE（Latent Safety Signals for Defense），针对现有解码阶段防御的两类问题：增强安全性可能增加对良性查询的过度拒答、损害有用性；许多方法依赖内部隐藏状态，受模型架构限制，并带来较大开销和跨模型泛化困难。LADE 从首个 token 的输出概率分布中提取安全信号，利用其中超出 argmax 所指最高概率 token 的信息，即作者所称的 dark knowledge。作者通过对比有害与良性查询，识别概率差异显著的 token，而不只关注表面的拒答 token。方法包含三个组件：选取安全判别性最强的 top-k token；通过 Tokenizer Mapping 将这些 token 映射到不同分词器；在映射后的 token 上进行 k 近邻（kNN）搜索以判别查询。作者报告，这些信号在不同 LLM 间呈现一致性，形成由安全对齐产生的模型无关方向。
适用任务
资料支持的应用方向是 LLM 的有害与良性查询判别，以及针对越狱攻击的安全防御，同时关注良性查询上的有用性与过度拒答问题。作者称在多种 LLM 和基准上开展评估，并报告对广泛越狱攻击具有鲁棒性；分词器映射用于支持跨模型应用。具体适用模型、架构、语言、领域、基准和攻击类型，以及覆盖范围的数量，未知：当前资料未提供。摘要不能支持对所有模型或所有越狱攻击均有效的结论。
作者报告的比较条件
摘要将现有解码阶段防御作为问题背景，特别指出其中许多方法依赖内部隐藏状态，但未列出实际实验比较方法的名称或数量。作者报告的结果为：LADE 在多种 LLM 和基准上降低攻击成功率，同时保持有竞争力的安全性与有用性权衡，并对广泛越狱攻击具有鲁棒性。这些均为定性报告。比较对象清单、数据集与样本数量、有害和良性查询比例、模型数量与规模、任务和攻击数量、硬件、计算资源及推理设置，未知：当前资料未提供。指标方面明确提及攻击成功率及安全性与有用性权衡，但指标定义、分母、单位、绝对数值、相对变化、逐条件结果、最高或平均口径，以及过度拒答率、运行时间和开销的测量结果，未知：当前资料未提供。top-k 的 k 值、kNN 的邻居数与具体计算设置也未给出。
证据限制
当前证据仅为摘要，未核对全文，所有方法性质与效果均应归属于作者报告，当前资料不构成独立复现。作者明确描述的是既有方法的安全性与过度拒答权衡、架构依赖、开销及泛化问题；摘要未明确陈述 LADE 自身的限制，也未提供其是否彻底解决这些问题的证据。作者关于跨模型信号一致性、攻击鲁棒性和有竞争力的安全性与有用性权衡的陈述，缺少可在当前资料中核查的定量结果。消融实验、统计不确定性、失败案例、分词器映射细节、近邻参考数据构建、跨模型评估划分、开放代码及独立复现信息，未知：当前资料未提供；不能据此断言这些验证或实现本身不存在。
