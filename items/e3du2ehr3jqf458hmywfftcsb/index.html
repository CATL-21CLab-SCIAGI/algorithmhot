GeoNatureAgent（GNA）提出面向地理空间与环境任务的工具调用智能体投产前评测框架与基准

GeoNatureAgent (GNA): A Framework and Benchmark for Pre-Production Evaluation of Tool-Using Agents on Geospatial and Environmental Tasks

AI 导读

GeoNatureAgent（GNA）研究提出工具调用智能体的投产前评测框架，通过固定的16工具MCP接口、任务集与确定性评分器比较模型能力和单案例成本。

基于摘要arXiv:2610.09112v1
研究变化
作者提出 GeoNatureAgent（GNA），用于工具调用型 LLM 智能体投入环境与地理空间工作流前的评估，检验其是否能针对真实 API 可靠地选择正确操作。框架将固定的 16 个地理空间工具发布为 Model Context Protocol（MCP）服务器，使用相同工具层、任务集和确定性评分器，使受测智能体成为作者设定的唯一变量；将能力与每案例成本作为两个独立维度报告。
适用任务
资料支持的直接评估对象是调用地理空间工具的 LLM 智能体，应用场景为环境与地理空间工作流的上线前评估。旗舰基准包含 103 个任务：覆盖 18 类的 93 个主任务，以及 10 个比较扩展任务；评估使用一个开放、可自行托管的地理空间 API，提供西班牙和葡萄牙范围内的 3 项环境指标，指标名称与具体任务类别未知。作者称替换工具执行器和任务集可为任意地理空间领域构建等价基准，但当前摘要未提供这些扩展领域的验证结果。
作者报告的比较条件
作者评估了 9 个 LLM，温度为 1.0，使用 3 个随机种子。作者报告：Claude Sonnet 4 能力最高，在全部 103 个任务上为 61.7% ± 0.7%，在 93 个任务的主任务集上为 60.8%；DeepSeek V3.2 随后，为 57.9%，其余模型均未超过 53%。摘要未说明 ± 0.7% 的统计定义，也未单独明确 DeepSeek 及其余模型数字的任务分母。成本—准确率 Pareto 前沿主要由开放权重模型构成；作者报告 DeepSeek V3.2 达到 Claude 能力的 93%，按标价计算的成本低 11.3 倍。该成本关系仅对应这两个模型的所报比较，不能推广为所有模型的降本幅度。采用严格的全部检查均通过计分时，作者报告最佳模型比通用 GIS 基准所报告的 85%—97% 低 24—36 个百分点；对排名前四的模型按检查项给予部分分数时，成绩为 86%—90%，与上述通用基准范围相近。作者据此认为差距很大程度上反映评分严格程度，而不只是任务难度。能力及部分得分以百分比报告，跨基准差距以百分点报告；具体通用 GIS 基准名称、是否同条件比较、其任务及模型数量、全部受测模型名单、每案例绝对成本与币种、标价时间、硬件、计算资源、运行时长及其他推理配置，当前资料均未提供。
证据限制
证据仅为用户提供的摘要，未核对全文，也无独立复现证据；所有结果均为作者报告。直接验证范围限于所述 9 个 LLM、103 个任务、3 个随机种子，以及服务西班牙和葡萄牙 3 项环境指标的 API，不能据此确认其他地区、指标或地理空间领域的表现。作者明确指出评分严格程度影响与通用 GIS 基准的成绩差距，因此不同评分口径的数字不能直接视为同条件能力差异。摘要未提供任务明细、完整检查规则、各模型完整成绩与成本表、除所述 ± 数值外的不确定性信息、统计显著性检验或实际生产部署验证。作者称 MCP 服务器、评估框架、基准和 API 均已公开，但当前资料未提供可核验的具体链接、实现内容或复现记录，不能将这一陈述写成已确认代码可用或已独立复现。作者明确陈述的其他方法限制未知：当前资料未提供。
