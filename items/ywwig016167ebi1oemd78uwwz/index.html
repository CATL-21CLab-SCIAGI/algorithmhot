CPathOGen 提出空间与形态可控的 H&E 反事实生成框架，用于探查病理模型

CPathOGen: Spatially and Morphologically Controlled H&E Counterfactuals for Probing Pathology Models

arXiv · 分子与定量生物学发表 2026-10-01 03:07 北京时间查看原文 ↗
基于摘要作者报告 · 独立复现未核验

CPathOGen 研究提出条件潜在扩散框架，通过控制细胞空间组织、细胞核形态与染色外观生成配对 H&E 反事实图像，以探查病理模型的敏感性。

研究变化

作者提出 CPathOGen：一种条件潜在扩散框架，用于生成成对的 H&E（苏木精-伊红染色）反事实图像，显式控制细胞空间组织、细胞核形态和染色外观。细胞图通过空间编码器约束空间结构，形态/外观向量通过逐块特征线性调制（FiLM）调节去噪过程。该方法针对常见像素空间与特征空间扰动可能产生不合理组织、使模型响应难以解释的问题。作者还提出 Biology-Nuisance Sensitivity Ratio（生物学因素与干扰因素敏感性比率），用于对比模型对具有生物学动机的形态及空间因素的敏感性，与对非生物学染色干扰变化的敏感性。

适用任务

摘要支持的对象为 H&E 组织学图像块及计算病理模型。作者报告在留出的 H&E 图像块上评估生成组织，并使用经其验证的可控干预，探测配有终点预测头的病理编码器、任务专用分类器及生存模型，以评估鲁棒性和受控特征敏感性。具体疾病、组织类型、临床终点和数据来源未知：当前资料未提供。

作者报告的比较条件

作者报告，在留出的 H&E 图像块上，CPathOGen 可生成视觉上合理的组织；经过空间引导筛选后，分布一致性改善，表现为更低的 Fréchet Inception Distance（FID）和 Kernel Inception Distance（KID）。摘要未明确上述降低所对应的比较基线，也未给出具体数值、增益幅度或平均/最高等统计口径。作者还报告，生成细胞的数量与位置跟随指定控制，测得的形态与颜色随相应控制单调变化，未提供定量误差或变化幅度。对下游模型响应，作者采用总变差距离和预测翻转率进行量化，并提出 Biology-Nuisance Sensitivity Ratio 对比生物学因素与染色干扰因素的敏感性；摘要未给出这些指标的数值结果、比率具体公式、预测翻转率分母或汇总方式。常见像素与特征空间扰动仅作为问题背景提及，摘要未提供与其直接比较的实验结果。数据集、图像块、模型及任务数量，硬件、训练与推理计算设置，指标单位和不确定性估计均未知：当前资料未提供。

证据限制

当前证据仅为摘要，未核对全文。组织视觉合理性、分布一致性改善、控制响应及模型探测用途均为作者报告，当前资料没有独立复现证据。摘要未明确陈述方法限制，也未提供详细实验协议、空间引导筛选规则、具体比较方法、消融实验、统计检验或跨数据集泛化验证信息，因此无法仅凭当前资料判断效果大小、稳定性和适用边界；这些信息缺失不代表研究本身未开展相关验证。资料包含 GitHub 与 Hugging Face 链接，但未核验链接内容，不能据此认定代码或模型可用，也不能视为已独立复现。
